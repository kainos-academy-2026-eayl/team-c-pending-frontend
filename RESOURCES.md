# Express and Nunjucks Resources

## Knowledge

- [Express: Using middleware](https://expressjs.com/en/guide/using-middleware/)
  Primary source for middleware, `next()`, and registration order.
- [Express 5: Application API](https://expressjs.com/en/5x/api/application/)
  Primary reference for `app.get()` and `app.use()`, path matching, and router mounting.
- [Nunjucks: Templating](https://mozilla.github.io/nunjucks/templating.html)
  Official reference for extending layouts and filling their named blocks.
- [MDN: What is CSS?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/What_is_CSS)
  Reference for the distinction between HTML structure and CSS presentation.
