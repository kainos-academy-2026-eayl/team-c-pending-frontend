Three layers of a page

Nunjucks: combines templates and fills blocks. {% extends "layout.njk" %} reuses the layout.

HTML: gives content structure. Use headings, paragraphs and links inside the content block.

CSS: controls appearance. Target a class to set colour, spacing and width.

<p class="confirmation-message">Thank you for your order.</p>

.confirmation-message {
    color: #245c39;
    margin-top: 1rem;
}

A block must have a place in the parent layout to appear there. A block named header does not automatically create an HTML heading.
