Express: get or use?

Choose by purpose

app.get(path, handler): handle GET requests matching a route, such as a page.

app.use([path], middleware): mount middleware or a router, without restricting the HTTP method. Without a path it defaults to /.

app.get('/account', handler) does not automatically match /account/orders. app.use('/account', middleware) matches both paths, but not /accounting.

Query strings are not part of the route path. GET routes also handle HEAD if no earlier matching HEAD handler was registered.

Matching handlers run in registration order. Respond to finish, or call next() to continue. Either kind of registration can use middleware.
