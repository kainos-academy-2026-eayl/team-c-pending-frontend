# Mission: Build Express pages with Nunjucks

## Why
Build pages for the academy frontend, choosing Express routes correctly and using Nunjucks, HTML and CSS to present their content.

## Success looks like
- Register a GET page handler.
- Mount middleware or a router and predict which requests reach it.
- Structure and style a Nunjucks page using its shared layout.

- Start with a short lesson and frontend examples.
