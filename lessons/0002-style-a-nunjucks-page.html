LESSON 02 / ABOUT 5 MINUTES

Nunjucks assembles. HTML structures. CSS styles.

Your win: turn a single confirmation sentence into a readable page with a heading, paragraphs and controlled spacing.

Start inside the content block

Your confirmation template extends the shared layout. Put ordinary HTML inside its content block; Nunjucks inserts that HTML into the layout's matching block. Source: Nunjucks inheritance.

{% block content %}
<main class="confirmation">
    <h2>Your order is confirmed</h2>
    <p>We will contact you when your order is dispatched.</p>
    <p>Thank you for shopping with us!</p>
</main>
{% endblock %}

The existing layout already has an h1 for Pending Studios, so this example uses h2 for the page heading. A paragraph is a separate HTML element; inserting a newline in plain template text does not create a new paragraph.

A detail from your layout: it has title, head and content blocks, but no header block. Your confirmation template's header block therefore has no matching slot to appear in. Put the visible heading inside content instead.

Add the appearance in CSS

Your layout already links to /common.css. Add page-specific rules to the stylesheet served at that URL. The class keeps these rules focused on the confirmation page. Source: MDN CSS.

.confirmation {
    max-width: 40rem;
    margin: 2rem auto;
    padding: 1.5rem;
    line-height: 1.6;
}

.confirmation h2 {
    color: #245c39;
}

.confirmation p {
    margin: 1rem 0;
}

max-width caps the content width; margin creates space outside the box; padding creates space inside it. color changes the text colour. A rem is relative to the root font size.

Predict, then check

Which layer changes the heading's colour?

A: The CSS rule.
B: The HTML tag.

Check your prediction

A. The heading tag provides structure; a CSS rule specifies its colour.

Which spacing creates room inside the confirmation box?

A: The margin property.
B: The padding property.

Check your prediction

B. Padding is inside the box; margin is outside it.

Your tiny practice task

  1. In your template, split the message into a heading and two paragraphs.
  2. Add the confirmation class and matching CSS rules.
  3. Reload the confirmation page. Confirm the heading is green and the paragraphs are separated.
  4. Change only padding to 3rem. Predict the effect, reload, then restore 1.5rem.

If the CSS has no effect, first check that /common.css loads successfully and that the class name matches your selector. If the heading is missing, check that it is inside the content block.
