LESSON 01 / ABOUT 4 MINUTES

One page, or a shared step?

Your goal: choose the right Express method when adding a frontend route.

Two different jobs

A request includes an HTTP method, such as GET, and a path, such as /account-menu. Opening a page normally sends GET.

app.get('/account-menu', accountController);

This registers a handler for GET requests to that route. Your controller can render the account page.

app.use(express.static('public'));

This mounts middleware: a function that can inspect a request, respond, or pass it on. Here, Express checks for public files, such as a stylesheet. If it cannot find a file, it normally passes control to the next handler.

Memory aid: get selects a request method and route; use mounts a step or group of routes.

Source: Express middleware guide

Why a path on use is different

app.use('/account', accountRouter);

A router is a group of routes. This mounts it under /account for any HTTP method. It can receive both /account and /account/orders. Inside that router, the matching paths are / and /orders.

By contrast, app.get('/account', handler) does not automatically match /account/orders. A path prefix must end at a segment boundary: /account does not match /accounting.

Source: Express Application API

Order matters

Express checks matching registrations in order. A handler that sends a response finishes the request. Calling next() passes control onward. Doing neither leaves the request waiting.

Neither method means "always runs": an earlier response can prevent later handlers from running. Also, GET routes can contain middleware; the distinction is not "middleware versus no middleware."

Source: control flow in Express

Try from memory

Say your answer before opening each explanation.

1. Display an order-history page on GET /orders.

A: Register with get.
B: Register with use.

Check answer 1

A. Use app.get('/orders', ordersController) for this method-specific page route.

2. Mount a router containing GET and POST routes under /orders.

A: Register with get.
B: Register with use.

Check answer 2

B. Use app.use('/orders', ordersRouter). The router's own routes choose the HTTP methods.

3. Does app.use('/account', middleware) match POST /account/orders?

A: It can match.
B: It cannot match.

Check answer 3

A. The prefix matches, and use does not restrict the HTTP method. It runs if the request reaches that registration.
